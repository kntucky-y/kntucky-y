## About me

I'm a **Computer Science student from Cebu, Philippines** and an aspiring
**AI automation engineer**. I build and ship full-stack applications across
mobile, web, desktop, and game development.

- Building products from interface to backend, deployment, and automation
- Exploring LLM integration, AI-assisted workflows, and practical automation
- Learning in public through projects, experiments, and my
  [Python journey](https://github.com/kntucky-y/pyjourney)
